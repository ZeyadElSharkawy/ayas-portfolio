Static instances of the site's fonts for generated Open Graph images (`next/og` can't read woff2 or
variable fonts). All three families are SIL Open Font License 1.1, from Google Fonts:

- `Fraunces-Light-opsz144.woff`, `Fraunces-LightItalic-opsz144.woff`: Fraunces, weight 300, opsz 144, Latin
- `InstrumentSans-Medium.woff`: Instrument Sans, weight 500, Latin
- `Alexandria-Regular-arabic.woff`: Alexandria, weight 400, Arabic subset
